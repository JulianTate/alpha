# Master specification

This implementation is the first safe vertical slice of the supplied specification: local SQLite schema, provenance-aware event storage, evidence-backed relationship graph, deterministic propagation/scoring, manual trade confirmation, outcome calculation, read-only Jarvis query helpers, optional Telegram adapter, and an offline end-to-end proof.

Not yet implemented: live SEC/price/news/macro adapters, historical analogue statistics, full backtesting, Luna cascade, automated exit monitoring, missed-signal lifecycle, Windows startup registration, and phone delivery. These are explicitly documented limitations, not placeholders presented as complete features.
